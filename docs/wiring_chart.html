micro:bit V2 ↔ TCS3200 (GY-31) Color Sensor — Project reference
5 wires go to the micro:bit edge connector (red, black, yellow, white, blue). 4 jumpers stay on the sensor module itself (S0, S1, OE, LED).

Main connections

Sensor pin Wire color micro:bit pin Purpose
VCC Red 3V Power (3.3V)
GND Black GND Ground
OUT Yellow P1 Frequency signal (sensor → micro:bit)
S2 White P2 Filter select bit 1
S3 Blue P8 Filter select bit 2

On-sensor jumpers (no wire needed)

Sensor pin Jumper to Purpose
S0 VCC (3V) Frequency scale HIGH (sets 20% or 100% scaling)
S1 GND Frequency scale LOW
OE GND Output Enable (active-low, must be grounded)
LED VCC (3V) Keep onboard white LEDs always on
